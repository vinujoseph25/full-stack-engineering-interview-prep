# Senior Full-Stack Engineering Interview Playbook

This repository is a structured interview-preparation knowledge base for senior and lead full-stack engineering roles.

## How to use this repository

Use the material in three passes:

1. **Refresh** — review the topic guide before an interview loop.
2. **Explain** — practise answering technical questions aloud without referring to notes.
3. **Apply** — connect each concept to a production example, trade-off, or incident from your own experience.

## Interview answer framework

For experience-based questions, structure answers around:

**Context → Problem → Decision → Trade-off → Outcome → Learning**

For architecture questions, structure answers around:

**Requirements → Constraints → High-level design → Data/API design → Reliability → Security → Observability → Scaling → Trade-offs**

## Personalisation checklist

Before using this repository in an interview, replace generic examples with concrete stories from your own work. Quantify impact where possible: latency, throughput, uptime, cost, delivery time, defect rate, adoption, or team productivity.

## Repository structure

- `1-HTML & Accessibility.pdf` through `16-Behavioral.pdf` — consolidated topic guides.
- `Notes/` — working examples, practical notes and topic-specific exercises.
- `docs/` — navigation and interview practice guidance.

The goal is not to memorise every answer. The goal is to demonstrate sound engineering judgement, clear communication, and experience-based reasoning.
