A complete semantic elements representation in html

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Semantic HTML Example</title>
  </head>
  <body>
    <header>
      <h1>Website Title</h1>
      <nav>
        <ul>
          <li><a href="#home">Home</a></li>
          <li><a href="#about">About</a></li>
          <li><a href="#contact">Contact</a></li>
        </ul>
      </nav>
    </header>

    <main>
      <article>
        <header>
          <h2>Article Title</h2>
          <p><time datetime="2024-06-01">June 1, 2024</time> by Author</p>
        </header>
        <section>
          <h3>Introduction</h3>
          <p>This is the introduction section of the article.</p>
        </section>
        <section>
          <h3>Main Content</h3>
          <p>This section contains the main content.</p>
        </section>
        <footer>
          <p>Tags: <span>HTML</span>, <span>Semantic</span></p>
        </footer>
      </article>

      <aside>
        <h4>Related Links</h4>
        <ul>
          <li><a href="#">Semantic Elements Guide</a></li>
          <li><a href="#">HTML Reference</a></li>
        </ul>
      </aside>
    </main>

    <footer>
      <p>&copy; 2024 Example Website</p>
    </footer>
  </body>
</html>
```

<header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>
